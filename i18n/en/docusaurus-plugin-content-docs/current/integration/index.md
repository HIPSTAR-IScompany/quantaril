# Connections to SphereOS and Fold

Quantaril's integration surface addresses node autonomy and conditions for exchanging meaning, causality, authority, and receipts.

| Surface | Responsibility to inspect |
|---|---|
| World and node | Local state, local clock, owner authority |
| SphereOS | World management, isolation, resources, and recovery contracts |
| Fold | Semantic and protocol connections, including Identity and Authority |
| IBD and other components | Storage, acquisition, and synchronization contracts |
| This site | Integration explanations and indexes of sources and verification states |

Sharing a diagram does not create implementation dependencies or inherited authority. State revisions, capabilities, inputs, outputs, failures, stops, and recovery conditions.

As a first experiment, consider two nodes with the same source state. Compare retained state, exchanged information, and lost context across connection, disconnection, and reconnection. Add commits and results only after running an implementation. A paper example does not establish a completed P2P runtime.
