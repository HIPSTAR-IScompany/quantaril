# Quantaril CloudとAQC

Quantaril Cloudは、特定のSaaS、API、RAG、DB、MCP connectorそのものではなく、情報存在論と分散観測を含む上位のクラウド概念です。AQCはその下位実装の一つであり、両者を同一視しません。

原典は、教会という装置と神そのものを区別する宗教的な説明を用います。その意味をサービス一覧へ置換せず、実装装置と構想を分けて読みます。

## 設計の問い

- 自分の状態・鍵・権限をどこへ置き、何を交換するか。
- 単一node停止後も何が残り、何が再実行できるか。
- 誰の観測・評価が、どのrevision・Worldに拘束されるか。
- 表現を変えても意味と作者性をどう持ち運ぶか。

P2P、E2EE、自己主権、思考ログ可搬性、分散観測は設計方向です。達成を名前だけで宣言せず、実装・測定・未解決を分けます。
